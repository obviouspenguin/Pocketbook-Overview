# Pocketbook

Pocketbook is a privately developed iPhone budgeting app for personal use. It helps track everyday spending, income, and planned bills in one place.

## Current features

- Record expenses and deposits, with merchants, categories, dates, and notes.
- Organize checking, credit-card, cash, and other payment accounts.
- Track paychecks and planned bills, including recurring payments.
- View monthly spending and the remaining budget.
- See the remaining budget in an iPhone Home Screen widget.
- Store budget records locally on the device using SwiftData.
- Export and import backups.

Pocketbook is built with SwiftUI and SwiftData and requires iOS 17 or later.

## Planned Plaid integration

The proposed integration will use Plaid Link to connect the developer's own supported financial accounts and Plaid Transactions to import transaction data for personal budgeting and reconciliation.

Planned functionality includes reviewing imported transactions, matching them to existing manual entries, and linking recorded payments to planned bills to avoid duplicate budget charges. Plaid integration is not yet implemented.

## About this repository

This repository provides a public overview of the project for reference during the Plaid trial application. Pocketbook's application source code remains in a separate private repository. This repository contains no financial records, bank credentials, or Plaid API keys.
